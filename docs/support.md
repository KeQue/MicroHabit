# Commito Support

Need help with Commito? Contact us at:

support@commito.app

## Common Issues

### I cannot sign in

Make sure you are using the same email or sign-in provider you used when you
created your account. If you use email sign-in, check your inbox for any
confirmation or password reset emails.

### I cannot join a league

Ask the league owner to send the invite code again. Invite codes must be entered
exactly as shown.

### My habit day did not save

Check your internet connection, then pull to refresh the league screen. Commito
only allows editing today and yesterday in the current MVP.

### I want to delete my account

Open the app, go to the Account menu, and choose Delete account. You will see a
confirmation before deletion is completed.

### I found a bug

Email support@commito.app with:

- The email address used for your account.
- The league name or invite code, if relevant.
- A short description of what happened.
- A screenshot, if possible.

## App Review Demo Support

If you are reviewing Commito for the App Store and need help accessing a demo
account or testing an invite flow, contact support@commito.app.
