## Common Help Topics

### I did not receive my confirmation email

- Check spam or promotions folders
- Make sure you entered the correct email address
- Try the resend option in the app

### I need to reset my password

- Open the Forgot Password screen in the app
- Request a reset email
- Open the reset link on the same device if possible

### I want to delete my account

- Open the in-app menu and use the Delete Account option
- If that flow fails, contact [support email]

### Notifications are not working

- Make sure notification permission is enabled on your device
- Check your system notification settings for Microhabit
- Confirm the reminder was enabled in the app
