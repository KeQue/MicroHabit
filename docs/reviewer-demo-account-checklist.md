# Reviewer Demo Account Checklist

Do not store real demo credentials in git.

## Account To Create

Create one production account for Apple App Review.

Suggested email:

```text
appreview@microhabit.app
```

If that address is not available, use any real email inbox you control.

Suggested password rules:

- At least 12 characters.
- Unique to this app.
- Stored in a private password manager.
- Replaced after App Review if desired.

## Setup Steps

1. Create the account in the production app or Supabase dashboard.
2. Confirm the email address if confirmation is enabled.
3. Sign in on the latest TestFlight build.
4. Create a free league named `App Review League`.
5. Set activity to `Daily walk`.
6. Toggle today's habit day once.
7. Confirm the account can sign out and sign back in.
8. Confirm Delete account is visible in the Account menu, but do not delete this account.

## App Store Connect

Paste the real credentials only into App Store Connect review notes.

Never commit them to:

- GitHub.
- The launch plan.
- Public policy/support pages.
- Screenshots.
