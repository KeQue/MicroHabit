# Microhabit App Review Notes Draft

## Sign-In

- Users can create an account with email and password
- Users can confirm email if email confirmation is enabled in Supabase
- Users can reset password from the Forgot Password flow

## Core Flow

- Users create or join a league
- Users open the league detail screen
- Users check in on eligible days
- Users switch between My View and Ranking

## Notifications

- The app requests notification permission for reminder notifications
- Notifications are used only for reminder and engagement flows

## Account Deletion

- Users can delete their account from the in-app menu on the league detail screen
